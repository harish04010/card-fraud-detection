# Data license

The ULB credit card fraud dataset (Dal Pozzolo, Caelen, Johnson & Bontempi, 2015, "Calibrating Probability with Undersampling for Unbalanced Classification", IEEE SSCI), collected by Worldline and the Machine Learning Group of ULB, is distributed under the Open Database License. It is downloaded on first run and not stored in this repository, because the file is larger than GitHub allows. The code here is MIT-licensed.
